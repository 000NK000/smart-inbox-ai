## What the video shows

The video is an edited sequence of actual UI captures from the isolated demo launched with `npm run demo`. It is a read-only product walkthrough, not a live AI or backend integration recording. The captures show working navigation, mailbox filtering, search, message details, application records, and a preloaded example suggestion. No write or confirmation action is executed.

## Privacy

- Messages, sender addresses, companies, roles, tasks, and weather are synthetic fixtures.
- Only the browser page is captured; desktop notifications, browser account details, and local filesystem paths are excluded.
- The demo has no backend API proxy, disables location access, and blocks unsupported requests.
- Every video scene states that it uses fictional data with no connected accounts or live AI. Suggestion scenes also carry a preloaded-example label.
- Real mail, credentials, databases, and private interview notes are not included.
